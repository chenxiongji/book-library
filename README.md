# 阳光读书 - 图书借阅管理小程序

微信小程序原生代码，完整实现图书扫码录入、电子书上传、多格式阅读、纸质书借还、阅读笔记分享、VIP充值等级管理等功能。

## 功能模块

| 模块 | 说明 |
|------|------|
| 首页 | 轮播图、搜索入口、统计概览、快捷操作、分类导航、推荐/最新图书、热门笔记 |
| 书库 | 全部图书浏览、分类筛选、纸质/电子筛选、搜索、网格/列表切换、排序 |
| 扫码录入 | 调用 wx.scanCode 扫描ISBN条码、自动填充图书信息、手动编辑、批量录入 |
| 电子书上传 | 从聊天记录选择文件(TXT/PDF/EPUB/MOBI等)、上传进度、填写信息、封面选择 |
| 电子书阅读器 | 分页阅读、字号/背景切换、目录导航、阅读进度记忆、随书笔记 |
| 借阅管理 | 借阅/归还操作、借阅记录列表、到期提醒、逾期标识、借阅统计 |
| 图书详情 | 封面/信息展示、借阅/阅读入口、阅读进度、关联笔记、相关推荐 |
| 笔记广场 | 全部/热门/我的笔记、搜索、点赞、关联图书跳转 |
| 写笔记 | 选择关联图书、标题/章节/内容编辑、字数统计、发布 |
| 笔记详情 | 全文阅读、点赞、分享、关联图书跳转 |
| VIP中心 | 等级展示、进度条、权益说明、6级等级体系、充值记录 |
| 充值中心 | 5档套餐选择、微信支付模拟、积分到账、升级提示 |
| 个人中心 | 用户信息、VIP卡片、快捷统计、功能菜单 |

## 技术架构

- **框架**: 微信小程序原生 (WXML + WXSS + JS)
- **数据层**: 本地存储 (wx.setStorageSync)，utils/store.js 封装全部数据操作
- **组件**: 3个自定义组件 (book-card / empty-state / vip-badge)
- **页面**: 14个页面，4个Tab页 + 10个子页面
- **VIP体系**: 6级等级 (普通→青铜→白银→黄金→钻石→至尊)，积分驱动自动升级

## 如何运行

1. 打开 **微信开发者工具**
2. 选择「导入项目」
3. 项目目录选择 `book-library` 文件夹
4. AppID 可选择「测试号」或填入自己的 AppID
5. 点击确定即可预览

> 数据使用本地存储模拟，首次启动会自动写入示例数据（6本图书、3条笔记、1条借阅记录）
> 如需接入真实后端，替换 `utils/store.js` 中的方法为云函数或API调用即可

## VIP等级体系

| 等级 | 名称 | 所需积分 | 借阅上限 | 借阅周期 |
|------|------|----------|----------|----------|
| 0 | 普通会员 | 0 | 5本 | 14天 |
| 1 | 青铜读者 | 100 | 10本 | 21天 |
| 2 | 白银读者 | 500 | 15本 | 30天 |
| 3 | 黄金读者 | 2,000 | 20本 | 45天 |
| 4 | 钻石读者 | 5,000 | 不限量 | 60天 |
| 5 | 至尊读者 | 10,000 | 不限量 | 90天 |
